# Script de l'enregistrement d'écran pour App Review (60–90 s)

## Avant de filmer
- iPhone physique, iOS à jour, Devine-moi 1.1.0 (3) installé via TestFlight.
- Ajouter « Enregistrement de l'écran » au Centre de contrôle (Réglages → Centre de contrôle).
- Mode Ne pas déranger activé (pas de notifications à l'écran), batterie et réseau visibles sans importance.
- Idéalement, une partie du jour pas encore jouée (sinon montrer le résultat déjà obtenu, c'est acceptable).
- Préparer mentalement un mot de 5 lettres facile à taper (ex. ROUTE, PLAGE).

## Déroulé
| Temps | Écran / action |
|---|---|
| 0–5 s | Centre de contrôle → Enregistrement de l'écran (compte à rebours 3 s). Revenir à l'**écran d'accueil iOS**. |
| 5–10 s | Toucher l'icône Devine-moi : lancement, écran d'accueil du jeu avec les deux cartes (Mot du jour, Mot brouillé). Aucune connexion, aucun compte. |
| 10–30 s | Toucher **Mot du jour**. Taper 2–3 mots au clavier, valider : les plaques changent de couleur. Terminer si possible ; la fiche **résultat** s'ouvre (statistiques, Partager, lien Wiktionnaire). Toucher **Partager** pour montrer la feuille de partage iOS, puis l'annuler. Fermer la fiche. |
| 30–38 s | Onglet **Entraînement** : montrer une grille vierge, taper un mot. |
| 38–40 s | Toucher la plaque du titre pour revenir à l'accueil. |
| 40–58 s | Toucher **Mot brouillé**. Poser des lettres, utiliser **Mélanger**, **Indice**, **Effacer** ; trouver un mot si possible (une lettre jaune s'ajoute). |
| 58–64 s | Bouton **?** : l'aide (Comment jouer), puis fermer. |
| 64–70 s | Bouton **Statistiques**, puis fermer. |
| 70–82 s | Bouton **Réglages** : sons, musique, mode difficile, contraste élevé, clavier ; faire défiler jusqu'aux crédits (Lexique, Dicollecte, Kenney, omfgdude, Fraunces). Fermer. |
| 82–90 s | Toucher l'icône **musique** (coupe/relance), puis arrêter l'enregistrement (barre/pastille rouge ou Centre de contrôle). |

## Conseils
- Filmer d'une traite, sans montage ; gestes lents et posés.
- Le son n'est pas indispensable (micro coupé).
- Ne pas ouvrir le lien Wiktionnaire en entier : il quitte l'app vers Safari (le mentionner suffit).
- La vidéo est dans Photos : la joindre dans App Store Connect (réponse dans Resolution Center ou champ « Notes » / pièce jointe de la version).
